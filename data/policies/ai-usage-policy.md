# Acme AI Usage Policy

## 1. Overview

This policy governs the use of third-party AI tools, including large language
models, code assistants, and image generation services, by Acme employees. The
goal is to enable productivity without compromising data security, compliance,
or intellectual property.

## 2. Prohibited inputs

You must never paste confidential customer data, personal data covered by GDPR,
trade secrets, source code subject to export control, or unreleased financial
results into public AI services. Public AI tools include any service whose
prompts or outputs are used for model training or stored outside Acme's
approved tenancy.

## 3. Approved tools

The following tools are approved for general use: Acme's internal model
gateway, the enterprise plan of our code assistant, and any tool hosted inside
the Acme cloud environment. Other tools require an exception request approved
by the CISO and Data Protection Officer.

## 4. Output review

Any AI-generated output used in customer deliverables must be reviewed by a
qualified human before release. The reviewer must confirm factual accuracy,
absence of weakened work, and compliance with this policy.

## 5. Disclosure

Disclosure requirements vary by purpose. AI-assisted code used in
customer-facing products must be flagged in the design record. AI assistance
that only suggests wording in internal documents does not require disclosure.

## 6. Incident reporting

Suspected violations, accidental data exposure, or unusual AI tool activity must
be reported to security@acme.example.com within 24 hours.
